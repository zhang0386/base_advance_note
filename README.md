# base_advance_note

> 个人编程学习笔记与项目代码备份。

本项目包含了我的编程进阶学习路线中的相关代码、压缩包及学习笔记。主要用于日常记录、复习以及防止文件丢失。

## 📁 目录说明

- **python.zip**: Python 基础语法及练习题代码
- **python_ad.zip**: Python 进阶学习代码（如面向对象、多线程、正则表达式、基础算法等）
- **Mysql.zip**: MySQL 数据库操作练习代码及 SQL 脚本
- **jupyternb.zip**: Jupyter Notebook 交互式编程代码及实验
- **note.zip**: 综合学习笔记文档
- **README**: 本仓库的说明文件

## 🚀 使用说明

1. 点击右上角的 **Code** 按钮，选择 `Download ZIP` 克隆或下载本仓库。
2. 在本地解压对应的 `.zip` 文件即可进行查看和学习。
